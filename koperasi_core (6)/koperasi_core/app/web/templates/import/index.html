📖 Aturan & Format Data
  • member_number: Nomor unik anggota koperasi (Business Key).
  • nik: 16 digit angka KTP. Tidak boleh ganda.
  • email: Alamat email unik dan valid.
  • employee_id: Nomor pegawai (opsional, jika karyawan).
  • membership_date: Format YYYY-MM-DD atau DD/MM/YYYY.
  • Saldo Awal: Dikelola terpisah melalui ledger saldo awal untuk integritas audit finansial.
